# 🚀 Sistema de Gestão de Rentabilidade

Esta é uma aplicação web desenvolvida para automatizar o cálculo de margem de lucro, permitindo que microempreendedores analisem custos e rentabilidade de produtos de forma rápida, precisa e acessível a partir de qualquer dispositivo.

## 🛠️ Tecnologias Utilizadas
- **Python**: Lógica central e processamento de dados.
- **Pandas**: Manipulação eficiente de datasets e análise de métricas.
- **Streamlit**: Interface web interativa para deploy ágil.

## 📈 Funcionalidades
- **Processamento de Dados**: Importação de arquivos CSV de vendas e custos.
- **Análise Automatizada**: Cálculo de lucro líquido considerando taxas, fretes e embalagens.
- **Visualização**: Interface amigável para conferência de métricas em tempo real.
